# Assets attribution

## Visual style

Pixel-art tiles, characters, bombs, explosions and power-ups in this game are **original procedural sprites** generated at runtime (see `public/render.js`). They are inspired by the classic Bomberman maze aesthetic (green floors, brown soft blocks, warm fuse orange) but are **not** copies of Hudson Soft / Konami / NES assets.

## Optional CC0 references (inspiration only)

If you replace or extend sprites with external packs, prefer CC0:

- [Bombman 2D Resources](https://opengameart.org/content/bombman-2d-resources) — Drummyfish, CC0
- [Bomberman Explosion Effect](https://opengameart.org/content/bomberman-explosion-effect) — Satik64, CC0
- [Bomb Animation 24p DX](https://opengameart.org/content/bomb-animation-24p-dx) — Umplix, CC0

## Audio

UI and game SFX are synthesized with the Web Audio API (`public/sfx.js`) — no third-party samples.
